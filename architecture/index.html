System Overview

Factory Inventory Management System is a full-stack web application for managing factory inventory, orders, and supply chain operations. Built with Vue 3 frontend and FastAPI backend, it provides real-time inventory tracking, order management, demand forecasting, and financial reporting.

Architecture Pattern

Client-Server architecture with stateless REST APIs. Frontend communicates with backend via HTTP requests with query parameters for filtering. In-memory data provides fast response times suitable for demo and small datasets.

Key Features

Real-time inventory tracking, multi-filter search, order management, demand forecasting, backlog tracking, spending analysis, quarterly reports, and role-based task management with international language support.

Filter System

4-dimension filtering system: Time Period (months/quarters), Warehouse, Category, and Order Status. Filters propagate through Vue components → API client → FastAPI backend → JSON data filtering → Computed properties.

Data Models

Inventory items with stock levels and costs, Orders with customer and status tracking, Demand forecasts with trends, Backlog items with purchase order status, and Spending summaries with category breakdown.

Reactivity Model

Raw data stored in Vue refs (allOrders, inventoryItems), derived data computed via computed properties for efficiency. Real-time updates when filters change without manual refresh.

Performance Characteristics

In-memory data enables <10ms query response times. Computed properties cache results until dependencies change. No database latency. Suitable for datasets up to ~10K items.

Layer Details

Frontend Layer

App.vue: Root component managing navigation, header, and main content routing.

Views: 7 page-level components (Dashboard, Inventory, Orders, Spending, Demand, Reports, Backlog).

Components: Reusable UI components for filters, modals, charts, tables, and user menu.

Composables: Shared logic for authentication, internationalization, and filter management.

API Client: Centralized Axios instance for all backend communication.

Network Layer

Frontend Port: 3000 (Vite dev server)

Backend Port: 8001 (FastAPI uvicorn)

Protocol: HTTP/REST for development

CORS: Middleware allows all origins in dev

Headers: Content-Type application/json

Backend Layer

FastAPI Framework: Python async web framework with automatic API documentation.

Routes: 13 endpoints across 6 resource categories.

Filters: Sequential filtering logic for warehouse, category, status, and month.

Validation: Pydantic models ensure type-safe request/response handling.

API Docs: Auto-generated Swagger UI at /docs

Data Layer

Format: JSON files in server/data/ directory

Loading: Parsed at server startup via mock_data.py

Storage: Python dictionaries in memory during runtime

Persistence: Changes don't persist (server restart reloads from files)

Files: inventory.json, orders.json, demand.json, backlog.json, spending.json

Data Flow

Data flows through the system in a request-response cycle: user interactions trigger filter updates, which initiate API calls to the backend, which processes filters and returns data that updates the frontend state and re-renders the UI.

Data Flow Steps

1. User Interaction

User selects filters in FilterBar component (Time Period, Warehouse, Category, Status).

2. State Update

Filter selection updates Composable state (refs). This triggers watchers and computed properties to re-evaluate.

3. API Call Initiation

Vue component calls api.js with current filter values as query parameters. Axios builds request with URL-encoded filters.

4. Network Request

HTTP GET request sent to FastAPI backend: GET /api/endpoint?warehouse=X&category=Y&status=Z&month=M

5. Backend Processing

FastAPI route receives request, extracts query parameters, loads in-memory data, applies filters sequentially.

6. Data Filtering

apply_filters() function filters by warehouse, category, status. filter_by_month() filters by month/quarter. Filters are additive (AND logic).

7. Validation

Filtered data validated against Pydantic model. Any type mismatches raise validation errors. Valid data serialized to JSON.

8. Response

FastAPI returns HTTP 200 with JSON response body containing filtered results array.

9. Frontend State Update

Axios receives response, parses JSON. Vue component updates reactive refs (allOrders, inventoryItems, etc.) with new data.

10. Computed Properties Recalculate

Any computed properties depending on updated refs automatically recalculate. No manual triggers needed.

11. Template Re-render

Vue detects ref changes, marks component as dirty, re-renders template. Only changed DOM nodes update (virtual DOM diffing).

12. UI Display

User sees filtered results updated on screen. Process is fast (<100ms typically) due to in-memory data and efficient Vue rendering.

Return JSON array of 25 items ↓ Vue receives response, updates items ref with 25 items ↓ Computed properties recalculate (totalValue, lowStockCount, etc.) ↓ Template re-renders showing 25 filtered items with updated stats ↓ User sees results in <100ms

Filter Parameters

Warehouse

Filter by physical warehouse location. Valid values: "all", "Portland", "Seattle", "Denver", "Chicago", "Atlanta"

Category

Filter by product category. Valid values: "all", "Electronics", "Machinery", "Raw Materials", "Finished Goods"

Status

Filter by order status. Valid values: "all", "Pending", "Processing", "Delivered", "Backordered"

Month

Filter by month or quarter. Examples: "2025-01", "Q1-2025", "Q2-2025", or "all" for no filter

Quick Start Guide

Get the Factory Inventory Management System up and running in minutes. The system starts both frontend and backend servers automatically.

Prerequisites

  • ✓ Python 3.10+
  • ✓ Node.js 18+
  • ✓ npm or yarn package manager
  • ✓ Git for version control

Installation Steps

1. Clone the Repository

git clone https://github.com/your-org/inventory-management cd inventory-management

2. Start Backend Server

cd server uv run python main.py # Server runs on http://localhost:8001 # API docs available at http://localhost:8001/docs

3. Start Frontend Server

cd client npm install # Install dependencies (first time only) npm run dev # Frontend runs on http://localhost:3000

4. Access the Application

Frontend: http://localhost:3000

Backend API Docs: http://localhost:8001/docs

Troubleshooting

Port Already in Use

If port 3000 or 8001 is already in use, kill existing processes or change port configuration in the respective server files.

API Calls Failing

Ensure backend is running on port 8001. Check browser console for CORS errors. Verify CORS middleware is enabled in FastAPI.

Data Not Loading

Verify JSON files exist in server/data/. Check file paths in mock_data.py match actual file locations. Review backend console for errors.

Styling Issues

Clear browser cache (Ctrl+Shift+Delete). Restart frontend dev server. Check for CSS conflicts in browser DevTools.
